## BUG-01

- Заголовок: Заявка с темой api не сохраняется.
- Требование: R7.
- Версия/режим/окружение: workshop-1.0 / normal / Chromium 155.0.8059.80 / http://localhost:3000.
- Предусловия и точные данные: Стенд сброшен; API-лаборатория, Content-Type: application/json.
- Шаги воспроизведения:
  1. Отправить POST /applications с телом `{"name":"Анна","email":"anna@example.com","topic":"api"}`.
  2. Выполнить GET /applications/{id}, подставив id из ответа POST, и GET /applications.
- Ожидаемый результат: POST 201; GET по id 200, заявка присутствует в списке.
- Фактический результат: POST возвращает 201 и id, GET по id возвращает 404, в списке заявки нет.
- Свидетельство: POST 201, GET по id 404; в GET списка записи нет.
- Влияние на пользователя: Пользователь получает подтверждение, но запись на мастерскую теряется.
- Предложенный приоритет и обоснование: Высокий; заявка не сохраняется при успешном ответе.
- Гипотеза причины, если есть: Заявки с topic `api` исключены из добавления в базу, `backend/server.mjs:107`.

- Требование: R5.
- Версия/режим/окружение: workshop-1.0 / normal / Chromium 155.0.8059.80 / http://localhost:3000.

## BUG-08

- Заголовок: Форма отправляет заявку с пустым именем.
- Требование: R2.
- Версия/режим/окружение: workshop-1.0 / normal / Chromium 155.0.8059.80 / http://localhost:3000.
- Предусловия и точные данные: Стенд сброшен; имя пустое, email `anna@example.com`, тема "HTML и CSS".
- Шаги воспроизведения:
  1. Заполнить email и тему, имя оставить пустым.
  2. Нажать "Отправить заявку" и проверить Network.
- Ожидаемый результат: Форма показывает ошибку имени, POST не отправляется.
- Фактический результат: POST отправляется, сервер возвращает INVALID_NAME. Имя из одного символа форма блокирует.
- Свидетельство: В Network появился POST с пустым именем; ответ содержит `INVALID_NAME`.
- Влияние на пользователя: Неверная форма отправляет лишний запрос к серверу.
- Предложенный приоритет и обоснование: Низкий; сервер корректно отклоняет неверные данные.
- Гипотеза причины, если есть: У имени нет `required`, пустая строка пропускает проверку: `frontend/index.html:34`, `frontend/script.js:79`.
